Сонник на айфон

Файл «апк» на айфон не ставится. Здесь установочный ярлык: приложение откроется с экрана Домой, как своё.

Поставить ярлык

Через профиль

  1. Откройте эту страницу в Сафари.
  2. Нажмите «Поставить ярлык».
  3. Разрешите загрузку профиля.
  4. Настройки → Основные → VPN и управление устройством → Сонник → Установить.

Без профиля

  1. В Сафари откройте сонник.
  2. Кнопка «Поделиться».
  3. «На экран Домой».
  4. Добавить.
