# Мусульманский сонник (та‘бир ар-руʼя)

Краткая карта **исламской** традиции толкования снов для нашего продукта.  
Не является фетвой и не заменяет учёного.

## Что это

- Наука/практика толкования: **та‘бир** / **тафсир** сновидений.
- Опора: **Коран**, **Сунна**, обстоятельства человека.
- Самое известное имя: **Мухаммад ибн Сирин** (Басра, VII–VIII в.) — символ осторожного, контекстного толкования.
- Современные «алфавитные исламские сонники» в интернете часто — **поздние компиляции** под именем Ибн Сирина; классический подход важнее словаря.

## Термины (из коранической/хадисной речи)

| Термин | Примерно |
|--------|----------|
| **руя** | видение / правдивое сновидение |
| **хулум** | сон (часто в контексте тревожного) |
| **манам** | сон / отдых |
| **мубашшират** | благие вести во сне |
| **та‘бир** | толкование |

## Три вида снов (классическая схема)

1. **Благие / правдивые (от Аллаха)**  
   Ясные, спокойные, могут утешать или наставлять. Их можно рассказывать близким / знающему.

2. **От шайтана**  
   Пугающие, хаотичные, толкающие к греху или тревоге.  
   Обычно: не придать большого значения, попросить защиты у Аллаха, **не разносить** всем подряд; в хадисах — также встать на молитву, сплюнуть налево, перевернуться и т.п. (по разным ривайатам).

3. **От мыслей / нафса**  
   Отражение дня, усталости, желаний, стресса. Чаще **не требуют** толкования.

Правило продукта: в мусульманском режиме **сначала** помочь классифицировать сон, **потом** предлагать символы.

## Принципы Ибн Сирина (практичные для UI)

1. Толкователь должен быть **осторожным**; можно отказаться, если данных мало.
2. Один и тот же образ у двух людей → **разный** смысл (вера, профессия, место, время, эмоции).
3. Повторяющийся сон / один сон у нескольких → чаще признак значимости.
4. Праведные сны часто **короткие и содержательные**.
5. День/ночь сами по себе не «отменяют» правдивость.
6. Важно состояние человека (набожность, грехи, текущие события) — не только картинка сна.
7. Толкование — **предположение**; окончательное знание у Аллаха.

## 9 правил (сводка по популярным исламским материалам)

Использовать как чеклист в приложении, не как жёсткий алгоритм:

1. Не толковать без знания и осторожности.
2. Учитывать личность и жизнь видевшего сон.
3. Повтор сна усиливает значимость.
4. Ясность и краткость — признаки «хорошего» сна.
5. Время суток не единственный критерий.
6. Не рассказывать дурной сон всем подряд.
7. После тревожного сна — зикр / молитва / защита (по сунне).
8. Не строить жизнь только на сне.
9. Лучше спросить знающего, чем «гуглить символ» наугад.

## Отличие от «Миллера»

| | Миллер / алфавит | Исламский та‘бир |
|--|------------------|------------------|
| Единица | слово-символ | сон целиком + человек |
| Цель | «что будет» | смысл, наставление, различение видов сна |
| Словарь | большой фиксированный | контекст важнее статьи |
| Этика | развлечение/примета | ответственность, скромность |

## Как сделать раздел в нашем соннике

```text
Мусульманский режим
  1. Вопросы: спокойный / пугающий / «просто день»?
  2. Подсказка по сунне (без фанатизма, с дисклеймером)
  3. Опционально: символ → краткое толкование в духе традиции
  4. Всегда: «это не вердикт учёного»
```

Структура записи символа:

```yaml
id: snake
traditions:
  islamic:
    short: "..."
    context_hints:
      - зависит от поведения змеи во сне
      - зависит от состояния человека
    sources_note: "наши формулировки / общедоступные пересказы традиции"
```

## Что **не** копируем

- Готовые алфавитные статьи с коммерческих «исламских сонников» дословно.
- Выдачи «это харам / это халяль» без оговорки.
