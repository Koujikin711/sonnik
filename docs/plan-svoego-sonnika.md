# План своего сонника

## Цель

Сделать **свой** сонник с несколькими режимами толкования и собственной базой символов (RU / позже TJ и др.).

## MVP (первый рабочий вариант)

1. Поиск символа по алфавиту.
2. Карточка: краткое + развёрнутое толкование.
3. Переключатель традиций: `свой` | `народный` | `мусульманский` | `психология`.
4. Дневник снов (текст + теги + дата).
5. Дисклеймер.

## Данные

Папка `data/` — JSON/YAML символов, которые пишем сами.

Пример:

```json
{
  "id": "water",
  "title_ru": "Вода",
  "tags": ["стихии", "природа"],
  "traditions": {
    "own": {
      "short": "Эмоции и течение жизни.",
      "long": "Чистая вода — ясность; мутная — путаница…"
    },
    "islamic": {
      "short": "Смысл зависит от вида сна и контекста человека.",
      "long": "…"
    }
  }
}
```

## Платформы (решим на Mac)

- Веб (быстрее всего для облачной работы)
- Telegram-бот
- Android / iOS позже
