# Обзор видов сонников

Справочник для проектирования **своего** сонника. Здесь — типы подходов и известные школы, **без** копирования чужих алфавитных толкований.

## Три большие группы

| Группа | Суть | Примеры |
|--------|------|---------|
| **Предсказательные (символьные)** | Образ = готовое значение / примета о будущем | Миллер, Хассе, «универсальные» алфавитные сонники |
| **Религиозные** | Сон толкуется через священные тексты и правила веры | Исламский (Ибн Сирин / та‘бир), христианские народные традиции |
| **Психологические** | Сон = про внутреннее состояние, не про «судьбу» | Фрейд, Юнг, Лофф |

Универсально «самого точного» сонника нет: выбор зависит от цели пользователя.

---

## 1. Классические / «народные» предсказательные

### Сонник Миллера (Gustav Hindman Miller)
- Один из самых популярных «алфавитных» сонников XX века.
- Символ → краткое предсказание или совет.
- Удобен для приложений: поиск по слову, много готовых статей.
- Минус: устаревает по культуре и деталям быта.

### Сонник мисс Хассе
- Простой язык, акцент на **деталях** сна.
- Часто связывают с **нумерологией** и датой сна.
- Хорош как «быстрый бытовой» режим в приложении.

### Сонник Цветкова (Е. П. Цветков)
- Делит сны на более «вещие» и «пустые».
- Сильный акцент на эмоциях, творчестве, «счастливых» снах.
- Ближе к эзотерике + саморазвитию, чем к сухому словарю.

### Сонник Ванги / «по Ванге»
- Обычно **не** авторизованный текст самой Ванги, а сборники «по мотивам».
- Мистический, пророческий тон.
- Для своего продукта: осторожно с авторскими правами и с претензией на «точность».

### Сонник Нострадамуса
- Исторически связан с XVI веком и астрологией/пророчествами.
- Современные «сонники Нострадамуса» — чаще поздние компиляции.
- Образы часто «глобальные», туманные.

### Славянский / русский народный
- Устные формулы: «если снится X — будет Y».
- Принципы: сходство, противоположность, созвучие, метонимия (часть→целое).
- Хорош как отдельный «фольклорный» слой в приложении.

### Другие популярные ярлыки в рунете
- Современный / эзотерический / ассирийский / кулинарный / интимный / Юрия Лонго / Шиллера-Школьника и т.д.
- По сути чаще: **компиляции** с разным тоном (быт, магия, интим), а не отдельные научные школы.

## 2. Психологические школы

### Зигмунд Фрейд
- Сон = исполнение (часто замаскированное) желания.
- Явное содержание vs скрытое.
- Много символов сводит к личной/сексуальной динамике.
- В приложении: режим «самоанализ», не «предсказание».

### Карл Юнг
- Архетипы, коллективное бессознательное.
- Сон **компенсирует** однобокость сознания.
- Повторяющиеся образы важнее разовой «приметы».
- Режим: «архетип / миф / тень / анима» и т.п.

### Дэвид Лофф
- «Сколько людей — столько толкований».
- Мало жёстких символов; много вопросов к чувствам и контексту жизни.
- Идеален как **мастер вопросов**: «Кто вы во сне? Что чувствовали? Что сейчас в реальности?»

## 3. Восточные и религиозные (кратко)

| Традиция | Ключ |
|----------|------|
| **Исламский та‘бир** | Коран, Сунна, типы снов, контекст человека — см. `musulmanskiy-sonnik.md` |
| **Индийские / йогические** | Связь с гунами, чакрами, кармой (зависит от школы) |
| **Китайские / даосские** | Инь-ян, стихии, иногда связь с календарём |
| **Каббала / Папюс** | Астральный план, духовное состояние |

## 4. Как это ложится в **наш** продукт

Рекомендуемая архитектура данных:

```text
symbol (ключ: «вода», «змея», …)
  ├─ tradition: miller | folk | islamic | freud | jung | loff | own
  ├─ short: краткое толкование (наш текст)
  ├─ long: развёрнуто
  ├─ tags: [животные, стихии, люди, …]
  └─ notes: оговорки (контекст, пол, эмоция)
```

Режимы UI:

1. **Быстрый словарь** — поиск символа (предсказательный слой).
2. **Мусульманский** — сначала тип сна + правила, потом символ.
3. **Психология** — вопросы Лоффа/Юнга, без «сбудется/не сбудется».
4. **Свой сонник** — пользовательские заметки и избранное.

## 5. Правовая и этическая рамка

- Не копируем тексты коммерческих сайтов/книг целиком.
- Исторические обзоры и структура — ок; чужие статьи толкований — нет.
- Для исламского раздела: уважать традицию (не выдавать развлечение за фетву).
- Дисклеймер в приложении: «не медицинский и не религиозный вердикт».
